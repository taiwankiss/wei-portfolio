專案介紹

本專案為共享停車品牌「USPACE 」所製作的官方 2D 動態宣傳影片（Motion Graphics Commercial）。

全片使用 Adobe After Effects 進行動畫編排與節奏掌控，以「找不到停車位嗎？」作為開頭痛點引導。影片結合手持智慧型手機的 UI 介面操作動態、向量插畫元素、智慧地鎖與車牌辨識情境，並以「時鐘與存錢筒」直觀視覺化「以分計費」的省錢優勢。在短短 20 秒之內，以高節奏感的視覺轉換，建立起科技、高效且極具吸引力的品牌廣告。

Project Overview

A high-energy 2D Motion Graphics commercial created using Adobe After Effects for USPACE, a smart parking app.

The video tackles a common driver pain point—”Can’t find a parking spot?”—and introduces USPACE’s key features within 20 seconds. Through sleek UI motion design, custom vector illustrations, and intuitive visual metaphors (like clocks and piggy banks for minute-based billing), the animation delivers a concise, visually compelling promo that drives app downloads.
